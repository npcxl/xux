# 介绍

XUX 是一个Vue3 UI 组件库。


## 为什么选择 XUX？


### 标准化设计

参考 Ant Design 等主流设计系统，提供统一的设计规范和组件 API，降低学习成本。

### 高性能

组件轻量化设计，优化渲染性能，保证在大数据量下流畅运行。

### 开发体验优先

- 完整的 TypeScript 类型支持
- 详细的文档和示例
- 活跃的社区支持

## 浏览器支持

- Chrome >= 90
- Firefox >= 88
- Safari >= 14
- Edge >= 90
- 移动端浏览器
