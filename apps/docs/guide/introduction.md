# 介绍

XUX 是一个专为电商平台打造的 Vue3 UI 组件库。

## 特性

- 🛒 **电商场景** - 专为电商平台设计，涵盖常见业务组件
- 🎨 **美观易用** - 开箱即用，界面美观，交互友好
- 📦 **按需引入** - 支持按需引入，减小打包体积
- 🔥 **TypeScript** - 完整的类型定义，更好的开发体验
- 📱 **响应式** - 支持多端适配，移动端优先
- 📖 **详细文档** - 提供详细的文档和实时预览

## 为什么选择 XUX？

### 电商场景优化

针对电商平台的常见需求，提供商品卡片、购物车、订单列表等专业组件，开箱即用。

### 标准化设计

参考 Ant Design 等主流设计系统，提供统一的设计规范和组件 API，降低学习成本。

### 高性能

组件轻量化设计，优化渲染性能，保证在大数据量下流畅运行。

### 开发体验优先

- 完整的 TypeScript 类型支持
- 详细的文档和示例
- 活跃的社区支持

## 浏览器支持

- Firefox >= 88
