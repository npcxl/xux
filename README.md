# XUX - Vue3 电商组件库

> 📦 npm 包名：`@xlui/xux-ui`

专为电商平台打造的 Vue3 UI 组件库，提供丰富的电商场景组件。

## 快速开始

```bash
# 安装依赖
pnpm install

# 启动文档站点
pnpm dev

# 构建组件库
pnpm build:ui

# 构建文档
pnpm build:docs
```

## 项目结构

```
xux/
├── packages/ui/          # Vue3 组件库源码
└── apps/docs/           # VitePress 文档站点（含组件预览）
```

## 特性

- 🛒 专为电商场景设计
- 🎨 开箱即用的美观组件
- 📱 响应式设计
- 🔥 TypeScript 支持
- ⚡️ 轻量高性能

## 发布

```bash
# 发布到 npm
pnpm publish:ui

# 或使用脚本
./scripts/publish.ps1  # Windows
./scripts/publish.sh   # Linux/Mac
```
